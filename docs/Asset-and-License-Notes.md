# Asset and license notes

## Repository status

No open-source license has been selected for this repository. The portfolio README does not describe the source or sample assets as MIT, Apache, Creative Commons or public domain. Source licensing and sample redistribution terms remain decisions for the project owner; no third-party ownership or redistribution rights are inferred here.

## Supplied sound assets

`PocketBonham/Resources/Kits/kit-1/` contains the nine WAV files supplied by the owner as Drum Kit 1. Their original filenames and bytes are retained. `manifest.json` records a SHA-256 hash for each file, and `scripts/kit-mappings/kit-1.json` records the reviewed musical mapping. The source package did not include a license document in the inspected folder.

## Development and codec fixtures

`PocketBonham/Resources/Kits/Development/` contains deterministic synthetic development sounds generated by `scripts/generate_fixtures.py`. They are explicitly labeled as fixtures in the app and are not presented as one of the owner's finished kits.

`Tests/BonhamCoreTests/Fixtures/` contains synthetic codec-test files. `scripts/generate_codec_fixtures.py` recreates these fixtures; its optional MP3 encoder dependency is `lameenc==1.8.1`. That encoder is a development-time tool and is not linked into the app.

## Visuals and runtime dependencies

The screenshots in `docs/images/` are captures of this application's simulator UI. App icon generation is recorded in `scripts/generate_icon.swift`. The app uses system typography and SF Symbols through Apple's UI frameworks.

There are no third-party runtime package dependencies in `Package.swift`. The project uses Apple platform frameworks and the local Swift/C++ targets. This inventory documents provenance; it does not grant a new license to any component.
